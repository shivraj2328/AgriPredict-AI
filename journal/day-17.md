## Objective

## Work Completed

- Created centralized Axios API configuration.

- Connected Login page with `POST /api/auth/login`.

## Authentication Flow

React Register
      ↓
Axios
      ↓
POST /api/auth/register
      ↓
Express
      ↓
MongoDB

## Login Flow

React Login
      ↓
Axios
      ↓
POST /api/auth/login
      ↓
bcrypt.compare()
      ↓
JWT
      ↓
Store Token
      ↓
Dashboard

## Protected API Flow

React
  ↓
Axios
  ↓
JWT from localStorage
  ↓
Authorization: Bearer <JWT>
  ↓
JWT Middleware
  ↓
jwt.verify()
  ↓
req.user
  ↓
Protected API

## API Endpoints Integrated

| Method | Endpoint             | Purpose                   |
| ------ | -------------------- | ------------------------- |
| POST   | `/api/auth/register` | Register user             |
| POST   | `/api/auth/login`    | Login user                |
| GET    | `/api/auth/me`       | Verify authenticated user |

## Security

- Password are handled only by the backend.
- JWT is generated by the backend.
- JWT is automatically attached to the protected Axios requests.
- Authentication is verified by backend middleware.
- Passwords are never stored in frontend code.
